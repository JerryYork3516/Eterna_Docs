## 5. 对 Studio Next 的上位约束

- Studio 负责数字居民的设计、编辑、验证、构建和发布。
- Aftelle 负责数字居民的加载、交互、表现、陪伴及个人运行入口。
- Runtime Core 负责数字居民逻辑、权限、任务、状态更新和能力调用的实际执行与调度。
- 数字居民十三层是 Studio 设计、验证和编译居民的上位结构；现阶段只能引用其固定顺序和概览边界。
- Resident Blueprint、Build、Artifact、Resident Release、Resident Instance Data 和 Runtime Instance 必须保持边界清晰。
- `.digital_resident` 是可移植 Artifact，不等于完整 Resident，也不等于 Resident Release。
- 居民长期记忆、关系历史、成长记录和持续状态的唯一权威来源是 Resident Instance Data Authority。
- Studio 不得保存或静默覆盖正式长期实例数据，也不承担数字居民的正式长期运行。
- Studio Next 不得改变 Eterna 和数字居民的上位定义；如需改变，必须先提升对应上位文档版本并完成审核。
- Studio Next 1.0 的当前范围不得把 Eterna Universe 的长期产品拓扑整体扩张为本阶段施工范围。
