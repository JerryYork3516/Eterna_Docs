## 今日核心摘要

本覆盖窗口出现三项可核验的国内 AI 生态变化：千问 AI 平台新增可灵 V3 Turbo 极速视频生成模型；无问芯穹 GenStudio 按公告下线一批旧版 DeepSeek、GLM、MiniMax 和 Kimi 模型并给出迁移建议；2026 中国国际大数据产业博览会在贵阳开幕，展区覆盖算力基座、数据供给、模型驱动、安全护航和智能体验。

今天的共同主题不是单一基础模型参数跃升，而是视频生成能力通过聚合平台扩大可接入性、模型服务进入版本淘汰与迁移周期，以及数据和算力基础设施继续围绕智能应用组织。智谱 GLM-5.3 权重是否在今日按第三方预告开放，尚未在智谱官方入口取得确认，因此不列为已确认事件。

## 今日重要新增

### 千问 AI 平台新增可灵 V3 Turbo 极速视频生成模型（官方日期：2026-08-27）

- 发生了什么：千问 AI 平台模型发布记录新增 `kling/kling-v3-turbo-video-generation`。官方模型说明将其定位为可灵 V3 Turbo 极速视频生成模型，支持文生视频和首帧图生视频；平台 API 文档列出 3–15 秒时长、720P/1080P 两档分辨率和异步任务调用方式。
- 信息状态：已确认（千问 AI 平台模型记录及 API 文档）。
- 可信度：高
- 重要度：中高
- 为什么值得关注：可灵视频能力通过千问平台进入统一 API 目录，降低国内多模态视频能力的接入和替换成本。对 Eterna Universe、Aftelle、Studio Next 的视频生成或多模态工作流而言，这是可实际评估的国内供应商入口；仍需单独核验区域、配额、价格、内容策略、延迟和结果稳定性。

### GenStudio 下线多家厂商旧版模型并要求迁移（官方日期：2026-08-28）

- 发生了什么：无问芯穹 GenStudio 更新日志显示，8 月 28 日已下线一批旧模型：DeepSeek 的 `deepseek-r1`、`deepseek-v3`、`deepseek-v3.1`、`deepseek-v3.1-terminus`、`deepseek-v3.2`、`deepseek-v3.2-thinking`；GLM 文本模型 `glm-4.5`、`glm-4.5-air`、`glm-4.6`、`glm-4.7`、`glm-5`；GLM 视觉模型 `glm-4.5v`、`glm-4.6v`；MiniMax `minimax-m2.1`、`minimax-m2.5`；以及 Kimi `kimi-k2.5`。文档分别建议迁移到 `deepseek-v4-flash`/`deepseek-v4-pro`、`glm-5.2`、`kimi-k2.6` 和 `minimax-m2.7` 等替代模型。
- 信息状态：已确认（无问芯穹官方文档）。
- 可信度：高
- 重要度：高
- 为什么值得关注：这是明确的模型可用性和兼容性变化，可能直接造成旧模型 ID 调用失败。对依赖第三方聚合服务的智能体、AI 编程和批量推理系统，模型生命周期、迁移验证和回滚策略比单次模型榜单更重要。该公告只约束 GenStudio，不代表对应模型在原厂或其他平台同步下线。

## Eterna 价值提取

### 直接有用

- **可灵 V3 Turbo**：新增国内视频生成接入候选，适合纳入多模态供应商矩阵，优先验证异步任务、首帧图生视频、时长、分辨率、延迟、失败重试和内容限制。
- **GenStudio 模型下线**：为模型路由和第三方依赖审计提供现实案例，影响域为模型与服务提供方、智能体、AI 编程和基础设施。
- **数博会数据与算力板块**：提示数据标注、算力基座、模型服务和安全护航需要作为一组基础设施条件观察，影响域为 Runtime Core、ECCS、多模态和国内运行环境。

### 值得跟踪

- **视频服务可用性**：可灵 V3 Turbo 在国内不同区域的实际可用性、价格、排队时间、音画能力和批量任务稳定性。
- **模型生命周期治理**：GenStudio 及其他聚合平台的下线提前量、替代模型兼容性、旧模型错误码和迁移窗口；关注是否提供别名、版本锁定和回滚机制。
- **数据闭环与安全**：数博会发布的词元、标注、数据基础设施和安全成果是否转化为公开标准、可验证数据产品或可调用服务。

### 暂无行动价值

- GLM-5.3 开放权重的第三方预告、社区热门排序和衍生权重不能证明官方发布、许可或安全评估完成。
- 数博会展览主题和宏观数据规模不构成 Eterna 的采购、接入或合规结论。
- 可灵模型目录上线不等于已完成 Eterna 任务集评测，不应直接替换现有视频供应商。

### Eterna 今日主控判断

- **值得立即关注的技术变化**：有。可灵 V3 Turbo 扩大了国内视频生成 API 候选，GenStudio 下线事件则要求关注依赖服务的模型生命周期；暂不修改代码。
- **值得持续观察的方向**：有。重点是视频模型的真实成本与稳定性、聚合平台迁移机制、数据—模型—场景闭环和安全审计。
- **模型与服务提供方风险**：中高。固定模型 ID 可能因平台下线而失效，聚合平台的替代模型不保证行为兼容；视频生成还存在区域、队列、内容审核和计费不确定性。
- **竞争与生态变化**：中高。国内生态正在从单模型竞争转向聚合目录、视频工作流、数据基础设施和可治理的服务生命周期竞争。
- **国内模型与平台机会**：新增可灵 V3 Turbo 作为视频供应商评估项；继续观察 Qwen、Kimi、DeepSeek、GLM、MiniMax 和腾讯云聚合服务的版本、价格与可用性，不因本日报直接切换。
- **对 Eterna 当前开发的直接影响**：暂不改代码、配置或正式路线；将“模型 ID 生命周期审计、替代模型回归、视频 API 供应商基线、数据与算力依赖清单”加入后续研究清单。
