## 今日重要新增

### 1. DeepSeek-V4-Flash-Vision-Exp 公开权重，提供原生视觉输入与本地部署材料

- 发生了什么：IT之家报道，DeepSeek-V4-Flash-Vision-Exp 于 2026-08-31 在 Hugging Face 上线并采用 MIT License。DeepSeek 官方模型卡现已公开模型文件、Tokenizer、提示编码参考实现和最小化 PyTorch 推理实现，模型规模标注为 305B 参数；模型卡列出图文输入、视觉模块和多模态智能体基准，并提供 Transformers、vLLM、SGLang 等部署入口。DeepSeek 官方 API 文档另显示，该模型可通过 `deepseek-v4-flash-vision-exp` 调用，图片按最多 384 词元计费，支持 Chat Completions、Messages、Responses 与 Files API。
- 信息状态：高可信新增；8 月 31 日公开权重的报道与官方 Hugging Face 模型仓库相互印证，仓库页面未给出精确发布时间，因此不推断具体时刻。API 平台上线日期为 2026-08-21，早于本覆盖窗口；本条今日新增只指公开权重和本地推理材料。
- 可信度：高（DeepSeek 官方模型卡与官方 API 文档 + IT之家报道）。
- 重要度：高。
- 为什么值得关注：国内开发者首次可直接取得该实验性视觉模型的官方权重、编码和推理参考，便于评估截图理解、图表分析、浏览器视觉和多模态工具链；但 305B 规模带来的显存、并行和运维成本仍然很高，且官方标注为实验版本，不应直接当作生产默认模型。
- 主要来源：DeepSeek 官方 Hugging Face 模型卡（https://huggingface.co/deepseek-ai/DeepSeek-V4-Flash-Vision-Exp）；DeepSeek API 文档《DeepSeek-V4-Flash-Vision-Exp Release》（https://api-docs.deepseek.com/news/news260821/）；IT之家《DeepSeek-V4-Flash-Vision-Exp 模型已开源》（https://m.ithome.com/html/996637.htm）。

- 可信度：高（中国网信网确认新闻发布会，数字中国建设峰会网站刊载央视新闻原文）。

## Eterna 价值提取

### 直接有用

- DeepSeek-V4-Flash-Vision-Exp 的官方权重、提示编码和最小推理实现，为 Eterna 的多模态输入、截图理解、图表解析与本地部署评估提供了可复现实验材料；MIT License 便于先做合规审查和离线技术评估。
- 中央网信办对高权限智能体、技能插件和越权行为的风险表述，直接支持 Runtime Core、ECCS 与数字居民的权限分级、工具白名单、沙箱隔离、审计留痕和人工确认设计。

### 值得跟踪

- DeepSeek 视觉模型的实际显存需求、推理吞吐、量化路径、国内稳定服务入口和实验版本升级节奏；在没有真实部署数据前，不把 305B 权重列为默认供应商。
- 国内智能体安全治理是否进一步形成可执行的测评、备案、插件签名和跨平台审计要求；重点关注高权限终端与技能生态。
- 多模态模型接入后，图片、文件和 Files API 的留存、删除、地域和内容安全边界。

### 暂无行动价值

- 仅凭模型卡基准分数、媒体标题或社区“接近某海外模型”的说法，不能决定 Eterna 切换默认模型或修改路线。
- 网安周活动本身不等同于新法规；在正式文本或接口要求落地前，不据此做合规结论。

### Eterna 今日主控判断

今日存在两项值得立即关注的变化：国内多模态开源权重的可获得性提高，以及监管层面对高权限智能体安全边界的明确提醒。技术机会在于用 DeepSeek 视觉模型开展受控离线评估；主要风险在于硬件成本、实验版本稳定性、图像数据治理和工具越权。竞争与生态变化为高，国内模型替代机会为中高，但当前没有足够证据支持更换 Eterna 默认提供方，也没有触发代码或正式路线变更。
